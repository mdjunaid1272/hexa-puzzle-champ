# docs/ index

- **`GAMEPLAY-SPEC.md`** — current, authoritative description of core
  gameplay (matching, stacking, transfer, clearing, cascades). Read this
  first for anything gameplay-related.
- **`hex-cascade-gdd.pdf`** — original design/technical doc. **Superseded
  for gameplay mechanics**: it describes an earlier match-3 /
  connected-component / gravity-cascade design that was deliberately
  replaced with the stack-transfer mechanic in `GAMEPLAY-SPEC.md`. Its
  non-gameplay sections (rendering architecture, camera, lighting, audio,
  performance strategy, file structure) are still broadly accurate and
  useful as background, but do not treat anything in its Parts E–L
  (Matching, Stacking, Cascade, Combo, Scoring, Spawn, Difficulty, Game
  Over) as current truth.
